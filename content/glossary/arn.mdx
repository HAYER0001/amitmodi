# Application Reference Number

An Application Reference Number is a unique alphanumeric code assigned to a taxpayer when they submit any application on the GST portal. It serves as proof of submission and allows tracking of the application status until processing is completed.

### Example
You apply for GST registration. Upon hitting submit, you receive ARN AA120721123456Z. You use this to track your registration status.

### When It Matters in Practice
It matters when tracking the progress of registration, amendment, cancellation, or refund applications on the GST portal.
