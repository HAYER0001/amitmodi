# Importer Exporter Code

An Importer Exporter Code is a crucial ten-digit business identification number issued by the Directorate General of Foreign Trade (DGFT) that is mandatory for anyone looking to start an import or export business in India.

### Example
You plan to import electronics from China to India. You must first obtain an IEC before customs clears your shipment.

### When It Matters in Practice
Required for all import/export transactions and claiming export benefits.
