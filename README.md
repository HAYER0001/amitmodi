# Amit Modi & Co.

Tax, GST and compliance practice — Suratgarh, Rajasthan.
Next.js 15 (App Router), TypeScript, Tailwind v4, deployed on Vercel.

## Run it

```bash
npm install
npm run dev
```

Everything runs from the repository root. There is no `site/` subfolder.

## Where things are

| | |
|---|---|
| **[PROJECT.md](./PROJECT.md)** | The handbook. Client inputs, deployment, leads, the assistant, design system, audits. Start here. |
| `docs/archive/` | The original brief and the build plan that produced this site. History. |
| `app/` `components/` `lib/` `data/` | The site |
| `tools/` | Asset pipeline (alpha-keying, optimisation) |

## Before launch

`PROJECT.md` §2 lists what the practice still has to supply. The blocking ones:
a Resend key (**without it the contact form silently drops every enquiry**), a
real email address, office hours, and latitude/longitude.
